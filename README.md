    To meet all your oxygen needs.
</h2>

MEGA Fluid Cell is a small addon for [MEGA Cells](https://github.com/62832/MEGACells) that adds a fluid counterpart to the **MEGA Bulk Storage Cell**.

## Items

Currently this mod only adds two items

- **MEGA Bulk Fluid Storage Cell**: Designed for infinite storage of a single fluid type.
- **MEGA Bulk Fluid Storage Component**: The crafting component used to create the **MEGA Bulk Fluid Storage Cell**. It is interchangeable with the corresponding **MEGA Bulk Storage Component**.
